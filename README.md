# omega-quiz-app

App trắc nghiệm cho đồ án Lập trình di động. Flutter + Firebase.

Nhóm Omega:
- Uy (trưởng nhóm) — nhánh `uy`
- Đỉnh — nhánh `dinh`
- Danh — nhánh `danh`
- Thịnh — nhánh `thinh`

Làm việc trên nhánh của mình, xong mở PR vào `main`, không push thẳng lên main.

Chạy thử:

```
flutter pub get
flutter run
```

Board công việc: https://trello.com/b/56zfgki0/omega-phần-mềm-kiểm-tra-trắc-nghiệm
Phiên bản Flutter SDK dùng chung : Flutter 3.50.0
